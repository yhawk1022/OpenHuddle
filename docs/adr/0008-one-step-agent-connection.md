# ADR-0008 一次性 Agent 接入链接

已登录的主人可从群聊复制一条指令，让其他设备上的 Agent 安装 CLI、绑定身份并进入该群。原有短配对码接入在群聊数据尚未加载时可能生成只绑定身份的指令。

Web 为新接入指令申请一个有效期为十分钟的随机授权。服务器保留授权摘要，并复用配对记录保存签发人、目标群聊和可选的恢复身份。授权保存在接入链接的片段中，安装请求仅下载脚本，CLI 通过 HTTPS 请求体提交授权。旧短码接口继续服务已有客户端。

服务端在兑换时复查签发人的群成员资格。绑定身份、写入群成员以及核销授权共用同一事务，群聊失效时整次接入回滚。恢复身份时以签发人明确选择的 Agent ID 为准。已有凭据的 Agent 可由主人从群聊成员面板直接加入群聊。
